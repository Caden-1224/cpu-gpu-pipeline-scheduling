# CPU-GPU 调度离散事件模型：结果报告

## 证据边界

本报告来自离散事件模型，时间单位为毫秒。它不测量 Linux `sched_ext`、eBPF 程序、GPU 驱动或真实硬件，因此不能用于声称实际部署性能。模型仅验证：在定义的流水线、资源和随机负载参数下，CPU 侧调度策略对端到端结果的影响。

## 方法

每个请求依次经过 CPU 预处理、CPU 提交、单 GPU 服务和 CPU 后处理。CPU 有两个非抢占式核心，GPU 为单服务台。比较 FIFO、静态提交优先和 GPU 队列反馈调度。后者在 GPU 队列长度不超过 1 时优先执行提交任务，其他时候优先准备后续任务。每个组合重复 30 次，种子为 1000 至 1029。

## 受限结论

- `steady`：相对 FIFO，GPU 反馈策略的 P99 延迟变化 -0.07%，吞吐变化 0.03%。相对静态提交优先，P99 延迟变化 0.02%。该观察仅适用于本模型参数。
- `cpu_contention`：相对 FIFO，GPU 反馈策略的 P99 延迟变化 -88.94%，吞吐变化 37.54%。相对静态提交优先，P99 延迟变化 -5.53%。该观察仅适用于本模型参数。
- `gpu_saturated`：相对 FIFO，GPU 反馈策略的 P99 延迟变化 -0.00%，吞吐变化 0.00%。相对静态提交优先，P99 延迟变化 0.00%。该观察仅适用于本模型参数。
- `bursty`：相对 FIFO，GPU 反馈策略的 P99 延迟变化 -1.10%，吞吐变化 0.73%。相对静态提交优先，P99 延迟变化 0.20%。该观察仅适用于本模型参数。
